# Game Design and Development Projects

A collection of interactive **Construct 3** games built around **educational** and **cybersecurity awareness** themes. Each game is playable directly in the browser via Construct Arcade—no installation required.

---

## Playable Games

1. **Alien Blaster** — Arcade-style game developed in Construct 3.  
   👉 [Play Alien Blaster](https://www.construct.net/en/free-online-games/alien-blaster-81146/play)

2. **Cat & Sushi** — Interactive game developed in Construct 3.  
   👉 [Play Cat & Sushi](https://www.construct.net/en/free-online-games/cat-sushi-81798/play)

3. **Cyber Gate** — Cybersecurity awareness game developed in Construct 3.  
   👉 [Play Cyber Gate](https://www.construct.net/en/free-online-games/cyber-gate-82987/play)

4. **Tap or Trap (Mobile Safety Quest)** — Mobile safety and cybersecurity awareness game developed in Construct 3.  
   👉 [Play Tap or Trap](https://www.construct.net/en/free-online-games/tap-trap-mobile-safety-quest-83766/play)

---

## Overview

- **Engine:** Construct 3
- **Focus Areas:** Educational concepts, mobile safety, and cybersecurity awareness
- **Access:** Playable online through the links above
